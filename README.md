# Blockchain-Based Certificate Verification System

## Overview

This project is a blockchain-inspired certificate verification system developed using Java and SHA-256 hashing. The system securely issues and verifies digital certificates using cryptographic hash values.

The project demonstrates:
- Digital certificate issuance
- SHA-256 hashing
- Certificate verification
- Tamper detection
- Blockchain-inspired security concepts

---

# Features

- Issue digital certificates
- Generate unique certificate hashes
- Verify certificates securely
- Detect invalid certificates
- Console-based implementation

# How It Works

1. Certificates are issued for students
2. SHA-256 hash is generated
3. Certificates are stored securely
4. Certificates are verified using hash values
5. Invalid certificates are detected
